# 2do-Parcial

# Descripción

Este programa Permite registrar productos, guardarlos en una lista y ver la información con sus impuestos.

**Funcionalidades**

1. Agregar productos

Se pueden registrar dos tipos:

**Electronicos**

- nombre

- código

- precio

- cantidad

- garantía

- impuesto: 18% ITBIS

**Alimentos**

- nombre

- código

- precio

- cantidad

- fecha de vencimiento

- impuesto: 8%

**Ver inventario**

Muestra todos los productos guardados con:

- datos básicos

- impuesto calculado

- precio final
